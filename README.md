# E-Commerce-AB-Testing-Analysis
## Project Overview

This project analyzes an E-Commerce A/B testing experiment to determine whether a new website version improves user conversion compared to the existing version.

The analysis focuses on comparing control and treatment groups, calculating conversion rates, performing statistical hypothesis testing, and deriving actionable insights for business decision-making.

## Key Objectives

- Analyze user behavior across different experiment groups
- Compare conversion performance between old and new website versions
- Perform statistical significance testing
- Identify whether the new version leads to better conversion outcomes
- Provide data-driven recommendations for product optimization

1. Data Cleaning and Validation
2. Exploratory Data Analysis (EDA)
